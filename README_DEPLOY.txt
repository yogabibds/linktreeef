PACOTE PRONTO PARA DEPLOY ESTÁTICO.

ARQUIVOS
- index.html        página completa
- _redirects        fallback de rotas para Netlify
- netlify.toml      publicação sem etapa de build

NETLIFY
1. Descompacte o ZIP.
2. Arraste a pasta edney-linktree-deploy para o Netlify Drop.
3. O arquivo principal já se chama index.html e está na raiz.

IMPORTANTE
- As imagens usadas no design estão incorporadas no próprio HTML.
- Não há dependência de pasta local de assets.
- Os links externos estão dentro do index.html.
- O Spotify é apresentado como playlists/curadoria da Laiá Music, não como perfil oficial de artista.
- Os 5 IDs diretos de playlists do YouTube estão incluídos, mas não foram associados a títulos específicos sem confirmação.
